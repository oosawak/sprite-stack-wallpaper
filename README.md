# Sprite Stack Wallpaper

スプライトスタック試作（変形戦闘機のWebGLゲーム）を、MacとWindowsのライブ壁紙アプリにするプロジェクトです。
作り方は本人の定番の形で、Web（HTML/JS）で作った中身を Tauri で包みます。

## どんな壁紙か（目指す形）

- 普段は自動操縦で海の上を飛び続ける。昼夜は本当の時計と連動する
- ストーリー仕立て: 時間が来ると「ミッション ― 敵機を迎撃せよ」「ミッション ― 戦艦を撃沈せよ」の帯が出て、自機が自律的に出撃して解決し、哨戒に戻る
- たまに遊べる: 操作すると30秒だけ手動操縦に切り替わり、放っておくと自動に戻る
- Web側の壁紙モード（#wallpaper）に上記まで実装済み（ゲーム本体 v0.28）。このアプリはそれを読み込んでデスクトップに貼る

## 構成

- `frontend/` — ゲーム本体のHTMLとthree.js（正本は sprite-stack-proto リポ。節目でコピーして取り込む）
- `src-tauri/` — Tauri v2 の殻
  - macOS: NSWindow をデスクトップレベル（CGWindowLevelForKey）へ下げ、マウス透過・全Space常駐にする
  - Windows: Progman へ 0x052C を送って WorkerW を作り、自ウィンドウの親にしてアイコンの背面へ入れる
- `.github/workflows/build.yml` — GitHub Actions で Mac / Windows の両方をビルドする（tauri-action、ドラフトリリース）

## 分担（大事）

- 編集と git はミューズの環境でできます
- ビルドと実行確認はこの環境ではできません。GitHub Actions に投げるか、本人の Mac でビルドして確認する形になります。Windows の実機確認も本人側です
- プラットフォーム接続部（壁紙化のOS APIまわり）は実機で調整が要る前提の初版です

## 表示する画面の選び方（複数モニタ）

既定はメイン画面です。起動したあとからでも切り替えられます。

- **Ctrl+Alt+1 / 2 / 3** … どのアプリを使っているときでも切り替え（グローバルショートカット）
- **1 / 2 / 3 キー** … 壁紙側にフォーカスがあるとき（Windowsでデスクトップをクリックした後など）
- 起動時点で決めたいときは、起動引数 `--monitor=1`（0始まり、0がメイン）か環境変数 `WALLPAPER_MONITOR=1`

## 操作（壁紙モード）

- 普段は完全自動で、マウスを動かしても操縦は奪われません
- 遊びたいときだけ **Mキー** を押すと30秒間だけ手動操縦になり、終わると自動に戻ります（画面右下に表示が出ます）
